# كلمة · Kalima

تطبيق حفظ الكلمات الإنجليزية بالمراجعة المتباعدة والذكاء الاصطناعي.
React Native (Expo) · Supabase · Gemini.

---

## التشغيل لأول مرة

افتح **PowerShell** في مجلد المشروع (`Desktop\kalima`) ونفّذ بالترتيب:

### 1. الحزم الأساسية

```powershell
npm install
```

### 2. باقي الحزم عبر Expo

> استخدم `npx expo install` مش `npm install` — Expo بيختار الإصدار المتوافق مع SDK 57 تلقائيًا.
> ده بيمنع 90% من مشاكل "الحزمة دي مش شغالة".

```powershell
npx expo install expo-router expo-constants expo-linking expo-status-bar expo-splash-screen expo-localization expo-secure-store expo-speech expo-haptics expo-image expo-updates expo-system-ui

npx expo install react-native-safe-area-context react-native-screens react-native-gesture-handler react-native-reanimated react-native-url-polyfill @react-native-async-storage/async-storage @expo/vector-icons

npx expo install expo-image-picker expo-file-system expo-sharing expo-blur expo-linear-gradient expo-notifications expo-sqlite

npm install @supabase/supabase-js @tanstack/react-query zustand i18next react-i18next base64-arraybuffer @gorhom/bottom-sheet
```

> `@gorhom/bottom-sheet` بيعتمد على `react-native-reanimated` و `react-native-gesture-handler`،
> والاتنين متثبّتين خلاص من الأوامر اللي فوق.

### 3. متغيرات البيئة

انسخ `.env.example` باسم `.env`:

```powershell
Copy-Item .env.example .env
notepad .env
```

واملأ `EXPO_PUBLIC_SUPABASE_ANON_KEY` بمفتاح anon من لوحة Supabase.

### 4. شغّل

```powershell
npx expo start -c
```

> `-c` بيمسح الكاش — مهم بعد أي تعديل في `.env`.

هيظهر لك **QR code**. امسحه من تليفونك.
(التليفون والكمبيوتر لازم يكونوا على نفس شبكة الواي فاي.)

> ⚠️ **لو Expo Go قال «حدّث النسخة» أو «آخر نسخة هي SDK 54»:**
> Expo Go بيدعم إصدار SDK واحد بس، والنسخة المتاحة لجهازك أقدم من مشروعنا.
> الحل هو **Development Build** — اتبع [`docs/DEV_BUILD.md`](docs/DEV_BUILD.md).
> كنت هتحتاجه بعدين على أي حال عشان الأيقونة وشاشة البداية والمكتبات النيتف.

## المتوقع على الشاشة

التطبيق دلوقتي فيه تدفق كامل. جرّبه بالترتيب ده:

### 1. حساب جديد

| الخطوة | المتوقع |
|---|---|
| شاشة الترحيب | لوجو كلمة + 3 مميزات + زرارين |
| «ابدأ دلوقتي» | فورم فيه اسم وإيميل وكلمة مرور |
| اكتب كلمة مرور أقل من 8 حروف | رسالة عربية تحت الحقل |
| سجّل بإيميل حقيقي | شاشة «بصّ في بريدك» |
| اضغط رابط التفعيل من إيميلك | ارجع للتطبيق وسجّل دخول |

### 2. شاشات الترحيب (بتظهر مرة واحدة بس)

اختار مستواك → هدفك اليومي → وقت التذكير → «يلا نبدأ».
بيتحفظوا في جدول `profiles` مع منطقتك الزمنية.

### 3. التطبيق

| التبويب | المتوقع |
|---|---|
| الرئيسية | اسمك، ستريك، شريط تقدّم الهدف، إحصائيات حقيقية من `get_home_summary`، وشريط حزم المواضيع |
| كلماتي | مكتبتك بالفلاتر والبحث والترتيب |
| المراجعة | تقدّم اليوم مقابل هدفك، تركيبة الطابور (جديدة/مراجعة/عصيّة)، ولمحة عامة |
| حسابي | صورتك واسمك ومستواك، وروابط الإعدادات والقانوني |

> «استكشاف» مش في شريط التبويبات — الشريط أربع تبويبات وزر `+` في النص.
> بتوصله من شريط «حزم جاهزة» في الرئيسية.

### 4. إضافة كلمة بالـ AI ⭐

> ⚠️ **لازم تنشر `enrich-word` الأول** — اتبع `supabase/DEPLOY_FUNCTIONS.md`.
> من غيرها زر «هات الكلمة» هيرجّع خطأ.

| الخطوة | المتوقع |
|---|---|
| اضغط «أضف كلمة» من الرئيسية أو زر `+` في كلماتي | شاشة إدخال بلوحة مفاتيح إنجليزية |
| اكتب `resilient` واضغط «هات الكلمة» | شاشة تحميل 3–6 ثواني |
| النتيجة | بادج «اتولّدت دلوقتي» + الترجمة والأمثلة والنطق وحيلة الحفظ |
| اضغط 🔊 | تسمع الكلمة |
| اكتب ملاحظة واحفظ | ترجع للشاشة السابقة والكلمة ظهرت |
| **اكتب نفس الكلمة تاني** | بادج **«من القاموس — فوري»** وأقل من نص ثانية |
| اكتب أول حرفين من كلمة موجودة | اقتراحات فورية تحت زر البحث |
| اكتب `asdkjhasd` | «ما لقيناش الكلمة دي في الإنجليزي» |
| اكتب كلمة عربية | «اكتب كلمة إنجليزية بحروف إنجليزية بس» |

**اختبار الكاش هو الأهم.** لو المرة التانية طلعت «من القاموس — فوري»، يبقى نظام
توفير تكلفة الـ AI شغال زي ما اتصمم.

### 4-ب. الأسئلة المتنوّعة

**لازم `0006_questions.sql` يتشغّل و`generate-questions` تتنشر.**

الأسئلة بيولّدها Gemini مع الكلمة في **نفس النداء** — 5 إلى 8 أسئلة مختلفة
الأنواع والصعوبة، مخزّنة في القاموس المشترك زي التعريف بالظبط.

> 🎯 **كل الأسئلة بالاختيار.** مفيش أي سؤال بيطلب منك تكتب. التنوّع في
> **صيغة السؤال** مش في طريقة الإجابة: إنجليزي→عربي · عربي→إنجليزي ·
> استماع · جملة ناقصة. (`0008_quiz_and_reminders.sql`)

| المتوقع | التفاصيل |
|---|---|
| أول لقاء بكلمة جديدة | بطاقة تنقلب — ما ينفعش نمتحنك في حاجة ما شفتهاش (`repetitions = 0`) |
| المراجعة اللي بعدها | اختيار من متعدد بالاتجاهين |
| بعد ٣ مراجعات | يدخل كمان الاستماع والجملة الناقصة |
| **نفس النوع مرتين وراء بعض** | مستحيل — المُنسّق بيستبعد النوع المستخدم في آخر مراجعة |
| الصعوبة | بتطابق نضج الكلمة: كلمة راجعتها 9 مرات بتجيبلك مشتّتات أقرب |
| إجابة صح وسريعة (< 4 ثوانٍ) | تقييم «سهلة» تلقائيًّا |
| إجابة صح وبطيئة (> 12 ثانية) | تقييم «بصعوبة» |
| إجابة غلط | الإجابة الصحيحة تتظهر بالأخضر مع شرح سطر واحد |

تحقّق من قاعدة البيانات:

```sql
select de.lemma, eq.kind, eq.difficulty, eq.prompt
from public.entry_questions eq
join public.dictionary_entries de on de.id = eq.entry_id
order by de.lemma, eq.kind;
```

> 🔒 الإجابة الصحيحة **ما بتغادرش قاعدة البيانات**. الخيارات بتترتّب عشوائيًّا على
> السيرفر والتصحيح بيتم هناك — يعني مفيش طريقة تشوف الإجابة من الشبكة.

### 4-ج. توضيح القصد والكلمات المرتبطة

| الحالة | المتوقع |
|---|---|
| اكتب `recieve` (إملاء غلط) | «هل تقصد…» مع `receive` كزر — اضغطه يبحث عنها فورًا |
| اكتب `bank` (أكتر من معنى) | «أي معنى صادفته؟» مع تمييز مختصر لكل معنى |
| اختار معنى غير الأول | بيتحفظ في ملاحظتك عشان المراجعة تتركّز عليه |
| اضغط أي مرادف أو ضد | شيت بيفتح بمعاينة الكلمة وزر إضافة بضغطة |
| مرادف موجود عندك خلاص | الشيت بيقول «لديك بالفعل» بدل زر الإضافة |
| اضغط مطوّلًا على مرادف | بينطقه بدل ما يفتح الشيت |

### 4-د. حزم المواضيع

**لازم `0007_packs.sql` يتشغّل**، ويُفضّل بذر `scripts/words-packs.txt` قبلها
(انظر [`scripts/README.md`](scripts/README.md)) — من غير البذر كل كلمة هتتولّد
عند فتحها وتتحسب من الحد اليومي.

| الخطوة | المتوقع |
|---|---|
| الرئيسية → شريط «حزم جاهزة» | ستة كروت أفقية: سفر · عمل · صحة · تكنولوجيا · حياة يومية · دراسة |
| «عرض الكل» | شاشة استكشاف بكل الحزم وشريط تقدّم لكل واحدة |
| افتح حزمة | 24 كلمة، وتحت كل واحدة ترجمتها لو كانت في القاموس |
| «أضِف الحزمة» | كل الكلمات الجاهزة تتضاف **فورًا وبدون أي نداء AI** |
| اضغط كلمة عليها ✨ | شيت بيولّدها عند الطلب زي أي كلمة جديدة |
| كلمة عندك خلاص | علامة ✓ خضراء بدل زر الإضافة |
| ارجع للحزمة بعد الإضافة | شريط التقدّم اتحدّث لوحده |
| **الوضع المبسّط** | شريط الحزم بيختفي من الرئيسية |

```sql
-- تقدّم المستخدم في كل حزمة
select p.slug, count(*) as words, count(uw.id) as mine
from public.topic_packs p
join public.pack_words pw on pw.pack_id = p.id
left join public.dictionary_entries de on de.lemma_norm = pw.lemma
left join public.user_words uw on uw.entry_id = de.id
group by p.slug order by p.slug;
```

### 4-هـ. امتحان كلمة واحدة

**لازم `0008_quiz_and_reminders.sql` يتشغّل.**

| الخطوة | المتوقع |
|---|---|
| افتح أي كلمة → «امتحنّي في هذه الكلمة» | ٦ أسئلة عنها لوحدها، كلها بالاختيار وبأنواع مختلفة |
| بعد آخر سؤال | نسبتك، وتقييم واحد مشتق منها، وشريط «مدى إتقانك» |
| **الامتحان بيتحسب مراجعة واحدة** | مش مراجعة لكل سؤال — وإلا امتحان من ٦ أسئلة كان هيقفز بالموعد قفزة كاذبة |
| «أعِد الامتحان» | أسئلة مخلوطة من تاني بنفس الكلمة |
| كلمة لسه ما اتراجعتش | «لا أسئلة لهذه الكلمة بعد» — بنك الأسئلة بيتولّد بعد أول مراجعة |

شريط «مدى إتقانك» مشتق من نفس شرطَي الإتقان في `srs_next`: فاصل ٦٠ يوم
(٦٠٪) و٦ مراجعات ناجحة (٤٠٪) — يعني الرقم ده معناه حقيقي مش تزيين.

### 4-و. مواعيد التذكير المتعددة

| الخطوة | المتوقع |
|---|---|
| الإعدادات ← مواعيد التذكير | تضغط أي ساعة تضيفها أو تشيلها، لحد ٦ مواعيد |
| آخر موعد | مش هيتشال — لو عايز تبطّل التذكير كله اقفله من المفتاح فوق |
| الإعدادات (الرئيسية) | المواعيد كلها ظاهرة جنب بعض |

### 4-ز. بطاقة الكلمة

كلمة من مكتبتك بتوصلك من غير ما تفتح التطبيق، بشكلين:

**١. أداة الشاشة الرئيسية (Widget) — أندرويد**

**محتاجة بناء جديد** (`npm run build:preview`) لأنها كود نيتف.

| الخطوة | المتوقع |
|---|---|
| اضغط مطوّلًا على الشاشة الرئيسية ← الأدوات ← «كلمة» | كارت زجاجي بتدرّج بنفسجي زي اللي في التطبيق |
| زر 🔄 | **يبدّل الكلمة في مكانها** — من غير ما يفتح التطبيق |
| زر 🔊 | **ينطق الكلمة في مكانها** بصوت النظام |
| اضغط الكارت نفسه | يفتح الكلمة دي في التطبيق (`kalima:///word/<id>`) |
| سيبها | بتتبدّل لوحدها كل نص ساعة |
| الإعدادات ← بطاقة الكلمة | معاينة حيّة للكارت + عدد الأدوات المضافة |

**٢. إشعارات الكلمات — الجهازين، اختيارية**

الأداة سلبية: بتستنى إنك تبص عليها. الإشعار بييجي لك. مفتاح منفصل في
«الإعدادات ← بطاقة الكلمة».

| الحالة | المتوقع |
|---|---|
| كل فترة | إشعار عنوانه الكلمة الإنجليزية وجسمه الترجمة — **كلمة مختلفة كل مرة** |
| بالليل | مفيش — الجدولة بين ٨ صباحًا و١٠ مساءً بس |
| كل ما تفتح التطبيق | الجدول بيتجدّد (٤٨ إشعار ≈ يومين) |
| سِبت التطبيق كذا يوم | بتخلص وبتهدأ لوحدها |

> ليه إشعار لكل كلمة بدل واحد متكرّر؟ لأن المتكرّر محتواه ثابت — هتشوف نفس
> الكلمة للأبد. و iOS بيسمح بـ ٦٤ إشعار مجدول للتطبيق كله، فبناخد ٤٨.

> **iOS:** الأداة لسه مش متعملة. ويدجت iOS بتحتاج WidgetKit extension بـ Swift،
> وده محتاج حساب Apple Developer عشان يتبني أصلًا. الإشعارات شغّالة على iOS دلوقتي.
> ولمّا تتعمل: تبديل الكلمة هيشتغل على iOS 17+، لكن **النطق هيفتح التطبيق**
> لأن iOS ما بيسمحش لأي ويدجت تشغّل صوت.

### 5. كلماتي وتفاصيل الكلمة

- **الفلاتر:** الكل / بتتعلمها / متقنة / صعبة عليك / المفضلة
- **البحث** بيدوّر في الكلمة الإنجليزية وفي الترجمة العربية
- **الترتيب:** الأحدث / أبجدي / الأصعب (بيختفي في الوضع المبسّط)
- **اسحب لتحت** عشان تحدّث القائمة
- **افتح كلمة:** ⭐ للمفضلة · 🚩 بلاغ عن خطأ · 🗑 حذف · ملاحظة شخصية · مقاييس التقدّم

### 6. المصادقة — اختبار كامل

| الحالة | المتوقع |
|---|---|
| كلمة مرور ضعيفة عند التسجيل | مقياس القوة تحت الحقل بيتلوّن أحمر → أصفر → أخضر |
| تسجيل بإيميل مسجّل قبل كده | «That email is already registered» |
| بعد التسجيل | شاشة «Check your inbox» مع زر إعادة إرسال بمهلة 45 ثانية |
| اضغط رابط التفعيل من الموبايل | التطبيق بيفتح ويسجّل دخولك |
| «Forgot password» | رسالة موحّدة سواء الإيميل موجود أو لأ (عشان محدش يعرف مين مسجّل) |
| اضغط رابط الاستعادة | التطبيق بيفتح على شاشة كلمة مرور جديدة **وأنت مسجّل دخول بالفعل** |
| رابط استعادة قديم | شاشة «This link has expired» مع زر يطلب رابط جديد |
| سيّب التطبيق ساعتين وارجع | لازم تفضل مسجّل دخول — الجلسة بتتجدد لما التطبيق يرجع للمقدمة |
| تسجيل الخروج | الكاش بيتمسح بالكامل، فالحساب التالي مش هيشوف كلمات الحساب السابق |

### 7. الإشعارات والإنجازات والأوفلاين

| الحالة | المتوقع |
|---|---|
| بعد أول جلسة مراجعة | شيت بيسأل «تريد تذكيرًا يوميًّا؟» — **مش عند أول فتح للتطبيق** |
| بعد الموافقة | تذكير يومي في الوقت اللي اخترته، وتذكير إنقاذ الستريك 20:30 لو الهدف لسه ما اتحققش |
| تحقيق الهدف | تذكير إنقاذ الستريك بيتلغي فورًا — محدش يتقاله «ستريكك في خطر» وهو خالص خلص |
| حسابي ← الإنجازات | 13 شارة، المفتوحة بتدرّج ملوّن والمقفولة بشريط تقدّم نحوها |
| **اقفل الواي فاي وراجع** | الجلسة بتكمّل عادي، والإجابات بتتخزّن محليًّا |
| افتح الواي فاي وارجع للتطبيق | الطابور بيتزامن تلقائيًّا وبيتحدّث كل شيء |

```sql
-- بعد المزامنة، لازم تلاقي المراجعات وصلت
select mode, count(*) from public.reviews group by mode;
```

### 8. اختبارات مهمة

- **الإعدادات ← المظهر:** بدّل الثيم وحجم الخط. **الوضع المبسّط** بيكبّر كل حاجة ويخفي تبويب «اكتشف»
- **الإعدادات ← تعديل البيانات:** غيّر اسمك وارفع صورة
- **سياسة الخصوصية والشروط:** بالعربي والإنجليزي — بدّل اللغة بزر `EN / ع` وهما مفتوحين والنص بيتغيّر فورًا. النسخة العربية هي المُعتمدة قانونيًّا، والإنجليزية ترجمة للتيسير ومكتوب ده فيها
- **الإعدادات ← الحساب:** «نزّل بياناتي» بيطلّع ملف JSON. وحذف الحساب موجود بس **محتاج نشر `delete-account` الأول** (`supabase/DEPLOY_FUNCTIONS.md`)
- **اقفل التطبيق وافتحه:** لازم يفضل مسجّل دخول (الجلسة في SecureStore)

### التحقق من قاعدة البيانات

```sql
select display_name, cefr_level, daily_goal, reminder_time, timezone, onboarded_at
from public.profiles;

-- الكلمات اللي اتولّدت
select lemma, cefr_level, ipa, audio_url is not null as has_audio,
       jsonb_array_length(senses) as senses, source
from public.dictionary_entries order by created_at desc;

-- استهلاك الـ AI الفعلي (لازم يقل عن عدد الإضافات بفضل الكاش)
select * from public.ai_usage;

-- مكتبة المستخدم
select de.lemma, uw.status, uw.due_at, uw.personal_note
from public.user_words uw join public.dictionary_entries de on de.id = uw.entry_id;
```

| `get_home_summary` فشلت | يبقى `0003_functions.sql` ماتشغّلش. راجع `supabase/RUN_SQL.md` |
| بادج الاتجاه بيقول LTR | طبيعي أول مرة على iOS. اقفل التطبيق وافتحه تاني |
| خطأ في Reanimated / worklets | `npx expo install react-native-worklets` ثم `npx expo start -c` |
| `Cannot find module 'babel-preset-expo'` | `npm install` تاني — الحزمة بتيجي مع `expo` |
| `Unable to resolve @/...` | تأكد إن `tsconfig.json` فيه `paths` وأعد تشغيل الخادم |
| عالق على شاشة التحميل | غالبًا `profiles` ماتعملش للمستخدم. راجع trigger `on_auth_user_created` في `0003_functions.sql` |
| «Email not confirmed» | افتح رابط التفعيل من إيميلك، أو فعّل المستخدم يدويًا من Authentication → Users |
| شاشات الترحيب بتظهر كل مرة | `onboarded_at` ماتحفظش — شوف اللوج لأي خطأ في `update profiles` |
| رفع الصورة بيفشل | تأكد إن `0002_rls.sql` اتشغّل (سياسات storage جوّاه) |

## قواعد ثابتة في الكود

1. **ممنوع `marginLeft` / `right` / `paddingLeft`** — استخدم `Start` و `End` بدلًا منها، وإلا الواجهة هتتكسر في RTL.
2. **الكلمة الإنجليزية دايمًا `ltr`** — استخدم `<Text ltr>` أو `english` في `Input`.
3. **أي عنصر قابل للضغط ≥ 48dp** — `minTouch` من `useTheme()`.
4. **الألوان من `useTheme().colors` فقط** — ممنوع أي hex في الكومبوننتس.
5. **مفتاح Gemini ما يقربش من التطبيق** — مكانه أسرار Supabase بس.
6. **منطق SRS في Postgres** — التطبيق بينادي `submit_review` وبس.
7. **أي نص بيشوفه المستخدم بيعدّي على `t()`** — ممنوع نص إنجليزي مكتوب في JSX.
   التطبيق عربي أولًا، والنص المكتوب في الكود بيفضل إنجليزي مهما بدّل المستخدم.
8. **ممنوع أرقام أو قوائم وهمية في الواجهة** — لو البيانات لسه مش جاهزة، اعرض
   حالة فاضية. الرقم الوهمي بيوصل للمستخدم على إنه حقيقي.
9. **ممنوع `letterSpacing` أو `textTransform` على نص مترجم** — الاتنين بيكسّروا
   وصل الحروف العربية.
