# تشغيل التطبيق والأداة على محاكي iOS

> **مش محتاج حساب Apple Developer.** المحاكي بيشتغل بدون توقيع، فالـ ٩٩ دولار
> مطلوبة للأجهزة الحقيقية و TestFlight بس.

## المتطلبات على الماك

- **Xcode 16** أو أحدث (macOS 15 Sequoia) — ده شرط `@bacons/apple-targets`
- CocoaPods 1.16.2+
- Node و npm

## الخطوات

**١. انقل المشروع** (من git بعد ما تعمل commit).

**٢. `.env` مش في git** — انسخه بإيدك:

```bash
cp .env.example .env
```

واملأ `EXPO_PUBLIC_SUPABASE_URL` و`EXPO_PUBLIC_SUPABASE_ANON_KEY` من نفس القيم
اللي على الويندوز. **من غيره التطبيق هيقع من أول لحظة.**

**٣. الحزم:**

```bash
npm install
```

**٤. ولّد مشروع Xcode وشغّل:**

```bash
npx expo prebuild -p ios --clean
```

```bash
npx expo run:ios
```

> `--clean` مهم أول مرة: إضافة `@bacons/apple-targets` بتضيف تارجت جديد لمشروع
> Xcode، والتوليد النظيف هو اللي بيضمن إنه يتربط صح.

## إضافة الأداة في المحاكي

1. سجّل دخول في التطبيق وافتحه مرة (عشان يبعت الكلمات للـ App Group)
2. ارجع للشاشة الرئيسية للمحاكي
3. اضغط مطوّلًا على أي مكان فاضي ← زر **＋** فوق على الشمال
4. دوّر على **كلمة** واختر الحجم واسحبها

## المتوقع

| | المتوقع |
|---|---|
| شكل الأداة | نفس الكارت الزجاجي اللي في التطبيق — تدرّج بنفسجي ولوح شفاف بحافة مضيئة |
| زر 🔄 (iOS 17+) | يبدّل الكلمة في مكانها بدون فتح التطبيق |
| زر 🔊 | **بيفتح التطبيق** على الكلمة وينطقها — iOS ما بيسمحش لأي أداة تشغّل صوت |
| اضغط الأداة نفسها | تفتح الكلمة في التطبيق |
| من غير لمس | بتتبدّل كل نص ساعة (جدول زمني ٦ ساعات مرسوم مقدمًا) |
| iOS 16 | زر 🔄 مش بيظهر — الإصدار ده مالوش أدوات تفاعلية أصلًا. الباقي شغّال |

> المحاكي مش بيحترم صلاحيات App Group، فالبيانات بتتشارك عادي من غير أي إعداد.
> على **جهاز حقيقي** لازم تسجّل `group.app.kalima.vocab` في حساب Apple بتاعك.

## لما تشترك في Apple Developer

ضيف الـ Team ID في `app.json` عشان تحذير الإضافة يختفي وبناء الأجهزة يشتغل:

```json
"ios": {
  "appleTeamId": "XXXXXXXXXX"
}
```

بتلاقيه في Xcode ← Settings ← Accounts، أو في لوحة developer.apple.com.

## تعديل الأداة

كود الأداة في `targets/widget/` — **مش** في `ios/`. مجلد `ios/` بيتولّد
وبيتمسح مع كل `prebuild`. في Xcode هتلاقي الملفات تحت مجلد افتراضي اسمه
`expo:targets`، وأي تعديل فيه بيتحفظ في `targets/widget/` على طول.
